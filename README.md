# 海洋浏览器 · JSON 采集专用（Web2Json）

基于 **PyQt5 + Qt WebEngine** 的桌面工具：用接近人工浏览的方式打开网页，自动捕获页面接口返回的 JSON，并可批量导出为 Excel。适合公开列表页、分页加载、滚动加载等场景下的数据采集与整理。

> **请合法使用本工具。** 禁止用于非法用途；不允许非法获取、使用或存储数据。使用者须自行遵守相关法律法规及目标网站服务条款。

---

## 功能特性

| 模块 | 说明 |
|------|------|
| 网页浏览 | 多标签、前进/后退/刷新、地址栏访问、新建窗口 |
| JSON 监听 | 捕获 `fetch` / `XHR` / 控制台中的 JSON，按条落盘 |
| 自动点击 | 配置坐标与间隔，辅助「加载更多」等操作；`Ctrl+左键` 拾取坐标 |
| JSON → Excel | 模板字段树勾选、自定义列名、批量文件/文件夹导出 |
| 调试面板 | 请求与操作日志（默认隐藏，可从设置打开） |
| 高 DPI | 适配不同屏幕缩放，减少字体显示异常 |

## 使用说明

### 1. 采集 JSON

1. 启动后打开目标网站（公开可访问页面）。
2. 点击工具栏 **▶ 开始监听**。
3. 在页面中正常操作（翻页、筛选、滚动等），触发接口请求。
4. 首次捕获到 JSON 时选择保存目录；之后自动写入文件。
5. 结束后点击 **■ 停止监听**；可用 **↺ 重置** 清空状态。

保存文件名示例：`yyyyMMdd_HHmmss_zzz_xhr.json`

单文件结构示例：

```json
{
  "timestamp": "2026-10-31 08:36:16.002",
  "source": "xhr",
  "data": { }
}
```

### 2. 自动点击（可选）

1. 点击 **⚙ 配置**。
2. 将鼠标移到目标位置，按住 **Ctrl** 再点左键，自动填入坐标。
3. 设置点击间隔；如需滚到底再点，勾选「每次点击前执行 Ctrl+End」。
4. 点击 **🖱 启动点击**；按 **ESC** 停止。
5. 可与「开始监听」同时使用，边点击边落盘。

### 3. JSON 转 Excel

1. 菜单 **设置 → JSON 转 Excel**。
2. **加载 JSON 模板**，在树中勾选要导出的字段（数组按元素展开为多行）。
3. （可选）开启 **自定义字段名称**，选中字段后双击「自定义列名」或按 `F2` 改为易读名称；导出表头将使用该名称。
4. **添加文件** 或 **添加文件夹**，批量加入待转换 JSON。
5. **一键导出 Excel**，自行选择保存路径与文件名。

### 4. 调试面板

- 默认不显示。
- **设置 → 显示调试面板**，或快捷键 `Ctrl+Shift+D`。

### 5. 帮助

- **帮助 → 简易操作指南**
- **帮助 → 关于**（含合法使用声明）

## 快捷操作

| 操作 | 说明 |
|------|------|
| 地址栏回车 | 加载网址 |
| ▶ / ■ | 开始 / 停止 JSON 监听 |
| Ctrl + 左键 | 配置窗口中拾取点击坐标 |
| ESC | 停止自动点击 |
| Ctrl+Shift+D | 显示 / 隐藏调试面板 |
| 标签栏双击 | 新建标签页 |

## 注意事项

1. 仅建议用于**有权访问**的公开信息；勿采集个人身份信息或未授权数据。
2. 自动点击会控制本机鼠标键盘，运行时请勿随意操作；紧急情况按 `ESC`。
3. 部分站点若有严格 CSP 或反爬策略，脚本注入或捕获可能受限。
4. 打包为 EXE 时，请将 `icon.ico` 与依赖资源一并打包。
